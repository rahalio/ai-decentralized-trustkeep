# Trustkeep — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Chief data officer

- As a CDO, I want a monthly trust operating review by journey, so that GDPR work funds growth rather than only risk avoidance.
- As a CDO, I want stale-PII cost burn-down on the same scoreboard, so that minimisation has a CFO-readable ROI.

### Journey owner / CMO delegate

- As a journey owner, I want opt-in and revoke trends for my acquire journey, so that I can see consumers voting with data in near real time.
- As a journey owner, I want monetisation blocked when trust dips, so that I do not spend against poisoned permission.

### Breach incident commander

- As an incident commander, I want a trust-recovery playbook with 72-hour regulatory and customer-communication tracks, so that handled-well breaches can rebuild loyalty.
- As an incident commander, I want post-incident trust proxies recorded, so that we learn whether recovery worked.

### Privacy program lead

- As a privacy lead, I want cross-functional decisions logged against journeys, so that we avoid a 100-node compliance maze.
- As a privacy lead, I want third-party sharing proposals gated, so that the 90% consumer hostility to resale is respected.

### Finance partner

- As a finance partner, I want estimated annual holding cost of inactive records, so that cleansing competes fairly for budget.
- As a finance partner, I want exception paths when cost models are wrong, so that we do not overstate savings.
